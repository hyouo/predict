# Research integration policy (2026-09-14)

This branch preserves main's runnable software unchanged and archives all 29 pre-existing non-main branch trees under archive/branch_snapshots. Snapshots are exact Git trees; workflows inside archive are inert. Old branch names, files and scientific claims are historical evidence, not current approval or a combined benchmark. No branch is deleted and no forced update is used.

Source histories are retained as merge parents. Local conversation archives contain substantial implementations not previously committed remotely; these are separately hash-indexed and supplied in the consolidated source package. Do not infer that an evidence-only old branch contains its complete implementation. The full integration archive keeps study namespaces separate and never pools incompatible outcomes, units, target budgets or test splits.

Stable baseline: retain the main software release. Research baseline: v7 shared response prior, RBF and simple context-quality variants remain reference comparators, not established modern-SOTA winners. All OP3, Sci-Plex, L1000 and GSE101406 cohorts used in prior development are exposed.

Active route: verified functional-information gain for a predeclared drug contrast across independent preparations, beyond static baseline and global sensitivity. First distinguish condition-mean prediction from within-preparation linkage; unknown native links must never be fabricated by a fitted alignment. The next local v14 study quantifies which verified bridge information could reduce decision ambiguity under explicitly hypothetical correspondence assumptions. It creates no biological pairing and is not a new prediction-accuracy claim.

Archive old metadata investigations and model variants; reopen them only for a specific unresolved gate. No default model replacement, journal submission, automatic performance release or paid computation is authorized by this integration.
