# v8 frozen-weight basal reconstruction diagnostic

Timing: added after reading the source-validation learning curves of the bounded TranSiGen adapter, before any v8 target scoring. It is a secondary validation-informed extension, not part of the original primary protocol. All original fits, settings and predictions remain unchanged and are retained.

Hypothesis: effect error may partly arise because predicted treatment is subtracted from a measured untreated profile in a new context whose baseline the model reconstructs imperfectly. At frozen weights define r(b)=b-E[decoder_x1(z1)|b], estimated with 256 fixed-seed draws. Each context receives ONE common reconstruction vector for every drug, so this correction cannot improve within-context centered drug patterns by itself. Predict q_tau(b,p)=q_original(b,p)+tau*r(b), tau in {0,.25,.5,.75,1}. No new target treatment information or network training is used. Unannotated drugs retain the original zero/fallback contract.

Choose tau and scalar amplitude on source validation contexts only. Also include residual-RBF fusion of q_tau using the original kernel grid and gamma grid, with all hyperparameters selected only on validation. Include a matched baseline-only prior r(b) with the same chemical coverage and search, no drug-specific neural prediction. Carry the selected rules to the original final refit weights. Score unchanged predictions and secondary variants jointly only after every prediction is hash-frozen. This is not a canonical author inference rule and will be named an adapted inference diagnostic. Do not attribute a gain from context-only shifts to improved drug-specific biology. Keep failed or disabled corrections and covered-subset reporting. Do not use this exercise to claim the original published TranSiGen method has been fairly defeated.
