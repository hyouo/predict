## Outcome and units
For each permitted profile calculate log2(1 + 1e6 * X / psbulk_counts). This is log relative abundance normalized to the upstream RETAINED-gene library, not absolute molecules/cell, not verified full-transcriptome CPM, and not the official signed-p-value Kaggle outcome. Subtract same-cell-type/same-plate control mean on the log scale. Average treatment replicates equally within cell type/compound. Do not use psbulk_cells as independent replicate counts. Retain all asset genes; no target-DE-driven filtering. Missing source profiles are never biological zeros: use available source estimates and record coverage; fill a missing source feature from the other observed source with an explicit flag in the audit.

## Reference separation
Sort the eight DMSO wells in each plate, identically across cell types. Control partitions: A=positions 0,3,6; B=1,4,7; C=2,5. A supplies model/reference baseline; B supplies independent-reference leave-compound-out validation; C is used only after prediction for final scoring. All three are disjoint physical wells. The primary rotation is A/B/C as above. Two fixed cyclic rotations are sensitivity analyses, not independent studies. No test-control data enter preprocessing, prediction, hyperparameter selection or the predictor API. Code must produce sample-ID access logs and reject private outcomes. Public query IDs may be read from metadata only.

Compare same-reference CV (held anchor minus A) against separated-reference CV (held anchor minus B), both finally scored against C. Both use the same treatment anchors and source responses. This explicitly tests sensitivity of model selection to common-control noise, without using final-control C for choosing parameters. Cross-context profiles from the same treated PBMC well can share assay/culture variation; this is a within-study cross-cell-type prediction, NOT donor/study-independent validation.

## Tracks and estimators
Zero-target-treatment track: zero effect, unscaled source mean, source-only globally calibrated mean, baseline-gated source transfer. Calibrated/gated coefficients are learned only from reciprocal T/NK source tasks. Source compound-group cross-validation chooses regularization. The gate uses source response times a low-degree function of target-minus-source untreated log abundance; it is an explicitly testable statistical hypothesis, not an inferred causal regulatory network. Include a fixed shuffled-baseline gate control.

Few-shot track: source mean; source mean plus target anchor residual offset; pooled source slopes; per-gene source-slope ridge shrunk toward a shared slope; source-response kernel ridge direct and residual; convex/LOO selected combinations only if fully specified before public read. Use only 12/11 target anchor compounds. Same-reference and separated-reference choices use identical candidate grids and fit information. Any novel-sounding component must be compared against its ordinary ridge/kernel equivalent.

Development may use only train/control A/B (no public or private treatment outcomes; no final-reference C). Fit/validation implementation errors may be corrected there. Before evaluation commit all exact candidate grids, implementation hashes and predicted arrays' SHA256. No iterative public leaderboard tuning: every registered model is reported, including losses. Models added after public opening require a separate post-hoc label and cannot be confirmed on this public set.

## Metrics and diagnostics
Primary: equal target-context macro MSE of public compound-level effect vectors across 5288 genes. Also report mean-row RMSE, MAE, cosine, gene-wise query-centered MSE, mean-bias MSE, compound retrieval/rank after removing training-estimated background, and per-context/per-compound losses. No overall-expression correlation as principal evidence. Separate zero-shot from few-shot comparisons. Use compound-cluster paired bootstrap for descriptive uncertainty only; correlated cells/controls and only two target contexts prevent treating genes, split rotations or cells as independent biological replicates.

Registered sensitivities: three control rotations; library denominator psbulk_counts versus retained matrix row sums; source permutation (fixed seeds) with matched fitting budget; predictor equivalence/unit checks; optional plate-excluded source prediction is a separately reported robustness diagnostic. Do not score private_test. No confidence interval for biological mechanisms, no causal identification, no claim to recover the full target-only gene response from this prefiltered panel.
