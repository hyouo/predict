# 006 — Source-only cross-view spectral consensus

2026-09-06. Exploratory follow-up after the existing RNA results, not a new confirmatory evaluation. The main remaining issue is biological signal, not just corrected validation. Test whether shared perturbation programs can be estimated more effectively than independent gene shrinkage, using the exact same two source contexts and ZERO target treatment observations.

Let M=(X1+X2)/2 and D=(X1-X2)/2 after centering each gene across source compounds. A working exchangeable-view model regards D D^T/G as nuisance covariance of M. This nuisance includes context-specific biological effects as well as measurement noise; it is NOT claimed to identify pure technical noise. Use N=D D^T/G+rho*trace(D D^T/G)/P*I, rho fixed separately at .1,1,10. Whiten M with N, eigendecompose its perturbation covariance, and retain Wiener-style weights max(1-1/eigenvalue,0). Restore the average source template using the previously frozen gene-consensus shrinkage coefficient. Also report the predeclared version applying that gene coefficient to the centered filtered response.

All six outputs are reported; rho=1 with gene-consensus weighting is the nominated default before these outputs are scored. No target baseline, anchor labels, public/private/evaluation controls or external test responses are inputs. Use existing sealed source matrices, the SAME OP3 private/leave-donor-out and sci-Plex targets/genes, and immutable output directories. Input array/shape/hash, source-only status and prediction seals are recorded. Compare to source_consensus_shrink and zero_shot source_scalar, not just unshrunk source copying.

This is a two-view empirical Wiener/low-rank shrinkage application, not an originality claim or a causal mechanism. Source views are not guaranteed independent. Shared batch errors and unequal context-specific responses can invalidate its working covariance. Report all failures, absolute and centered errors, and drug identification; no selection of a winning rho based on target outcomes.
