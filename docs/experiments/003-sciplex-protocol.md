# 003 — External sci-Plex: cross-context, cross-assay-panel transfer

Registered 2026-09-06 after OP3 public development and its first private evaluation, but BEFORE loading any sci-Plex treatment expression outcomes. The estimator code is fixed at commit 4779f0ed03c44a1e16757945ec2e81567420fb62. No new tuning grid or model architecture is selected using sci-Plex test performance. This is an independent study but not a prospective blinded wet-lab validation.

## Fixed input and measurement
Chem-PerturBridge sri­vatsan20_sciplex3_processed.h5ad, SHA256 8ad35a20e44bf41cb030a0f063eb6a5727965b8f27d0eda4380bda0e294ccc4c. Metadata audit: 4,974 pseudobulk rows, 56,799 genes, three contexts, 52 plate IDs. Restrict to 24 hours and 10 micromolar (floating point isclose), non-control psbulk_cells >=10 and positive psbulk_counts. All controls on relevant plates are retained regardless of their cell counts, with positive denominator required. Report low-cell controls, post-treatment QC selection and missing conditions. No individual cell or plate is called an independent donor. Integer count storage, finite/nonnegative counts, gene IDs and denominator compatibility must pass numeric checks before fitting.

## Role partition fixed using metadata only
Panel A = published plate IDs 1 through 24; panel B = plate IDs 25 through 48. Panels are defined assay groups, NOT asserted independent biological replicates: the published processed schema omits an explicit replicate field. Both have matching cell context and layout blocks, but matching does not alone establish biological independence. Plates 49–52 (72 hours) are excluded.
For each held-out target context (A549, K562, MCF7), use ONLY panel A observations in the other two source contexts. Target zero-shot predictor receives target panel A controls but no target treatments. Target few-shot predictor receives 16 panel A compound identities and their allowed outcomes. All target panel B data, including its controls, remain unavailable until predictions are sealed.
Eligible chemicals: common PubChem CIDs with >=1 qualifying 24h/10uM treatment row in every context and both panels. Missing CID rows are excluded with a list. Synonyms/duplicate rows with the same CID are ONE chemical group; never split them across training and test. Within a group, average row-level effects rather than call the rows independent biological replication. Actual treatment and control row budgets are reported.
Choose the same 16 anchor CIDs by sorting SHA256('predict-sciplex-v08|' + CID), with CID as a tie breaker. All other eligible CIDs are queries. No target anchor chemical occurs in the test set. Eligibility/selection uses metadata only, not effect size, p-values or target expression.

## Endpoint and controls
Define log2(1+1e6*count/psbulk_counts) per pseudobulk row, as in OP3, not signed p-values or an asserted DESeq2 logFC. Source effects subtract the mean of the two controls on their own panel A plate. For target anchors, obtain two reference versions using the two panel A controls separately, ordered by numeric original well column. Average within CID. Apply the frozen paired-reference CV correction and its ordinary-CV control. Target evaluation effects subtract the mean of both controls on their own panel B plate. This avoids directly reusing target evaluation control counts as model inputs.
Genes: for each target fold choose 4,000 genes with the highest mean log2CPM in source PANEL A CONTROLS only; stable original-index tie breaking. Every method uses that same source-derived gene set. No target expression, source treatment effect or test DE statistic selects genes. Report exactly this source-expressed-gene scope; target-only genes outside the panel are NOT claimed predicted. The underlying released all-gene universe and filtering history remain a limitation.

## Models, fitting, evaluation
Run all six source-only zero-shot baselines and the same 71-candidate/19-output few-shot bank in src/rna_models.py. Its fixed T/NK labels in diagnostics are overwritten with the actual source context identifiers; numerical code unchanged. Regularization/stacking weights use only complete-anchor leave-one-chemical-out criteria. All predictions for all three folds are sealed before any target panel B evaluation is run.
Primary: equal-target-context, equal-query-CID mean squared log2CPM effect error. Report gene lists, per-CID/per-context scores, mean-bias vs centered error, effect correlation and centered retrieval. Primary matched comparison is adjusted vs ordinary stacking with the same bank; compare to simpler adjusted bank, direct ridge and source-consensus shrinkage. Do not infer SOTA from weak baselines or compare to published scores with another endpoint.

A second seed, gene number, dose, QC threshold, within-panel test or readout-weighting change is a separate sensitivity analysis, not a rewrite of this first result. Significance is not manufactured from 4,000 genes or from reusing masks; compound intervals are conditional on these three cell lines and assay groups. All failures and worsening contexts remain in the report.
