# Multi-context v4: new-data test of baseline-conditioned response differences

Registered before local scientific analysis of the newly retrieved L1000 Phase II numerical slice. Earlier OP3 and Sci-Plex are development resources, not confirmation cohorts. This protocol does not claim SOTA or novelty for ridge/PCA/kernel ingredients.

## Acquisition and assay
Use the fixed public Chem-PerturBridge Phase II asset at revision 6c54c8eb0321cceff4f888c54e199077d055e20b; expected SHA256 34d198df9eddac5b535a0408794caaf41073fa014c74429d1050e483576fb581. Extract 24h and 10uM treatment observations plus all 24h controls. These are normalized L1000 landmark measurements, not single-cell counts: preserve their supplied scale after confirming upstream Level-3 provenance; never run RNA-count CPM normalization on them. Numerical extraction for byte-preserving transfer is not model fitting. Code may decompress whole NPZ chunks, but held-target outcome values may not enter scientific fitting, preprocessing or selection.

## Metadata-only eligibility and holdouts
Require usable within-cell/plate controls (>=4), divide sorted control well identifiers into two disjoint equal-as-possible halves A/B. Use A for baseline covariates and B for effect reference. At least 2 treatment observations per cell/compound and >=50 eligible compounds per cell context. No effect-size or DE significance threshold. All supplied landmark genes remain. Missing profiles remain missing. Select contexts using metadata only; order by SHA256('multicontext-v4-20260908:'+context_id). First max(2,ceil(0.2*C)), capped at 6, are test contexts; next equally many are validation; remainder train. Require >=4 training contexts, otherwise declare the planned task unsupported. Eligible scoring compounds require >=3 source contexts; all methods use exactly the same cell-compound masks.

## Models and development
Source mean; zero; learned scalar shrinkage; shared reduced-rank ridge; RBF baseline-weighted source interpolation; linear baseline kernel; additive context correction; raw-context interaction; source-support-centred interaction. Drug scores: up to 16 source-response PCs. Context scores: up to 6 source-control PCs. Ridge/width grid {0.01,0.1,1,10,100}; correction strengths {0,0.25,0.5,1}. Select each family on held validation contexts, not random cells or held drugs. Main criterion is macro cell MSE; also retain contrast-selected variants of the two interaction families. After selection, refit on train+validation contexts; freeze predictions for all test contexts together before test scoring. Primary target receives zero treatment calibration and only A controls.

## Hypothesis
For Y_cp=a_p+z_c B_p, the identity Y_tp=mean_{s in S_p}Y_sp+(z_t-mean_{s in S_p}z_s)B_p shows why prediction must account for the actual source support of each drug. Estimate a low-rank B_p with regularized baseline-by-drug interactions. This algebra is not claimed as a new theorem. The hypothesis is a reproducible positive increment beyond source-only/shared predictors, especially differences between two simultaneously held contexts with identical source information. No-baseline and uncentred variants must be independently tuned; improvement over a weak old baseline is insufficient.

## Evaluation and safeguards
Report absolute MSE, centred MSE, mean bias, cosine/retrieval, effect RMS, per-context failures, and paired-context difference MSE relative to zero difference. Pairwise checks use common drugs and the same fitted model/source set. Treat cell contexts and compounds as dependent clusters, not independent genes or replicates. Outcome-dependent signal subsets, if explored, must be explicitly post hoc and never replace the all-condition test. Keep full predictions, raw row identities, source hashes, selection risks and failures. No parameter changes after final scoring. Modern official State/MAP/PrePR-CT runs remain separately required before any SOTA claim; they are not represented by the local statistical baselines. No automatic merge or submission.
