# predict

跨细胞背景的化学扰动响应预测研究。

本仓库作为后续代码、统计假设、数据来源、实验协议和负结果的版本化工作记录。研究目标是检验：目标细胞的未处理基线及可信机制信息，能否为跨背景药物响应预测提供可独立复验的增量。

## 当前证据边界

接入基线为研究包 v0.7。既有数值研究主要来自一个辅助磷蛋白面板，是少样本目标背景校准，不是单细胞 RNA 的完全未见背景预测。尚无同任务独立 RNA 验证或相对最新方法的领先结论。

初始化正在将可运行源代码、测试、关键结果摘要和固定哈希的数据获取程序接入；完整历史实验数组不直接加入 Git。后续状态以 `STATUS.md`、实验记录和实际执行日志为准，不以聊天中的版本号替代 Git 提交。

持续集成用于验证代码，不代表有自主后台科研进程；不默认开启定时训练、付费计算或自动发布论文结论。
