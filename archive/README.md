# 历史归档

当前唯一维护、安装和使用的版本是 [`main`](../README.md)。这里保留早期研究与工程记录，目录中的版本号仅用于追溯，不代表多个可选产品。

- `branch_snapshots/`：此前保存的 29 份原始 Git 树，本轮不修改。
- [branch-heads-20261014.json](branch-heads-20261014.json)：本次收敛前全部 36 个分支的名称、提交和树哈希；这些提交必须保留为主线祖先后才能清理分支引用。
- `continuation_records/`：后续 v15/v16 分支独有的三个原始研究记录。它们未形成新的默认模型，也不表示本地对话中的完整研究源码已上传。
- `workflows/`：已完成的一次性整合、盘点和修复工作流的原文件；不再作为活动 Actions 工作流运行。

完整克隆中运行 `python -m tools.verify_history` 可验证清单的提交均可达，且 29 份快照树完全不变。历史文件可用 `git show <commit>:<path>` 查看；只有需要恢复历史开发现场时才另建本地分支。旧 PR 的讨论仍可在 GitHub 查看。

这些记录中的许可、数据约束与研究局限继续有效。根目录 MIT 许可不追溯重授本目录中的第三方材料或历史快照。
