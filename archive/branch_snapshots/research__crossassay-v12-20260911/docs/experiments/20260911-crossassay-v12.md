## Secondary conditional-mean feasibility (not the original zero-target-treatment task)
Question: does measuring a query drug's early P100 response improve prediction of its later L1000 mean, relative to allowed source-context RNA and simple sensitivity explanations? This explicitly uses target query-drug treatment P100; it is NOT query-free functional probing, novel-chemical prediction, or cross-preparation proof. Use only the30 exact compound-dose conditions shared across all six publisher base cells with same-detection-plate vehicle-referenced P100 and L1000 measurements. No expression-based condition selection. GCP is excluded from inputs because it is measured later than6h RNA. All978 landmark outputs are retained. Missing P100 values are imputed from training inputs only; missing RNA labels never become zeros.

Compute each response by subtracting its own assay/detection-plate vehicle mean, then averaging the available treatment records. Do not pair replicate ordinals or create Cartesian pseudo-pairs. Outer leave-one-base-cell-out; inner leave-one-source-cell-out selects parameters using context-macro MSE. This is one new conditional-mean feasibility comparison; not evidence that these six contexts are independent prospective experiments. Six biological backgrounds, not30x6 independent contexts. Unknown NPC provenance and upstream normalization dependencies remain explicit.
