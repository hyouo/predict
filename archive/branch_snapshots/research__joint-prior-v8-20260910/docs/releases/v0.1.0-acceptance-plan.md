# First usable release v0.1.0 — engineering acceptance plan

2026-09-07. Base repository commit: a193fc9aa5bc014c63738fb75b7e0d278d44fdd0.

This is an engineering release of an existing statistical research baseline, not a new algorithm superiority experiment. Historical research bundles contained two different v0.8 tracks; this release explicitly follows the latest supplied v0.8_source track: 11 B-cell / 10 myeloid calibration compounds, public development evaluation, private expression locked. Do not mix its scores with the earlier larger-calibration track.

## Fixed release model
Single-source T-cell per-gene slopes partially pooled toward the global slope, with gene intercept shrinkage. No source spectral truncation; do not trade drug-specific distinction for a smaller selected MSE. Target calibration uses pooled A–D controls; source reference uses C/D. Candidate penalties are 0.1,1,10,100,1000 and intercept fractions 0,.25,.5,.75,1. Whole-compound leave-one-out validation refits pooled and gene coefficients. Ties favor smaller intercept fraction and stronger regularization. This is the existing T_hierarchy_pooled_shrink comparator, not a novel mechanism model.

## Deliverables
An installable Python package and console command; separate prepare/train/predict/evaluate steps; a pinned OP3 adapter; portable numeric non-pickle models; gene and compound ID alignment; explicit effect-space/context/dose/time contracts; strict missing-data errors; non-overwriting outputs and failed-run records; prediction freeze manifests and provenance; ready-to-run example data/models; documentation, wheel and source snapshot.

## Acceptance
1. Unit tests cover algebra, serialization, shuffled genes, malformed inputs, overlap, nonfinite data, missing files, result protection, private-test and reserved-control guards, CLI and installation.
2. Run actual OP3 prepare/train/predict for both targets. Save both predictions before scoring either public target. No private outcomes may be decoded.
3. Report MSE, centered/bias decomposition, retrieval top-1, source-copy and zero baselines, all failure cases. Public data already used in development: label these reuse/engineering checks, not independent validation.
4. Compare the released predictor to the archived v0.8 single-source pooled-reference implementation under identical input and candidate budgets.
5. Install the wheel outside the repository, rerun inference and benchmark, compare predictions; verify installed model inference works without target labels or original HDF5.
6. Publish tested code on a branch/PR. Remote completion is stated only after checking actual GitHub results.

## Scope
Research-use first usable version, conditional on the upstream selected OP3 panel. Query compounds must have measured source responses and the target must supply at least four distinct calibration compounds. Not a new-drug, complete-unseen-context, single-cell distribution, calibrated uncertainty, ATAC, clinical, or SOTA solution. No new paid compute or unattended autonomous research is enabled.
