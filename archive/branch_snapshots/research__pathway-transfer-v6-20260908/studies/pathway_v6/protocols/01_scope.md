# Pathway-transfer v6: prospective analysis rules on already exposed development data

Registered 2026-09-08 before v6 numerical model evaluation. This is retrospective method development, not new independent validation: LINCS Phase II and the six v4/v5 test contexts were already analysed. No SOTA or causal identification claim is authorized by this protocol.

Data: reuse the exact hash-verified 24h/10uM LINCS L1000 Phase II slice and v5 eligible profiles, supplied 978 landmark genes, 18 training / 6 validation / 6 previously opened test contexts. No count normalization. Query compounds remain observed in >=3 allowed source contexts; held target treatment calibration is zero. Keep equal-context and reference-matched replicated interaction scoring unchanged. All methods receive the same source measurements and target untreated inputs, except explicitly declared external pathway priors.

Question 1: arithmetic-support centering and kernel conditioning are not equivalent to fitting a regularized regression with an unpenalized drug-specific intercept. Implement the latter (classical universal-kriging / centered ridge algebra), test exact shift and support-centering invariances, and compare against the original full-baseline kernel. No novelty is claimed for classical formulas.

Question 2: curated pathway membership may define a useful gene-local or pathway-aggregated geometry of untreated states. Acquire an official public Reactome GMT snapshot with byte limits, record URL/version when available, time and SHA256, retain upstream attribution, and select pathways using gene identifiers and membership only (no outcomes). Compare full baseline, pathway geometry, mixtures, identity/self-only geometry, and fixed gene-label-permuted pathway controls. Pathways are unsigned annotations, not established drug mechanisms. If acquisition fails, report the boundary and do not fabricate gene sets.

Tune regularization and predeclared kernel mixtures using the six validation contexts only. The fixed base grid is penalty {0.01,0.1,1,10,100}, mixture {0,0.25,0.5,0.75,1}; optional output shrinkage {0.25,0.5,0.75,1} is given equally to matched comparators. Fit the final rules to 24 allowed contexts and freeze predictions/code/input hashes before scoring the six old test contexts. Preserve both MSE-selected and interaction-selected choices as separate named estimators; never replace the primary selector after seeing test scores.

Report total, centered and bias error, drug retrieval, amplitude, reference-matched cell-by-drug interaction risk, per-context failures and query coverage. Test previously defined exclusion of source tissue labels matching held targets without retuning on test labels, compare on common query support. Source-family removal is an observational stress test, not a causal tissue effect. Retain adverse outcomes and failed runs. Any later extensions must be labelled and registered separately.

No paid compute, unattended research, journal submission, automatic merge, or modification of the released default model is requested. A finite public-data download workflow is permitted; model fitting remains local. Tests and refits are implementation checks, not biological replication.
