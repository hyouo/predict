# v11 post-primary sensitivity: sample-local loading versus information absence

Declared after the 38 initial predictor/measurement-space arrays were jointly frozen and scored. This is attribution/development, NOT a new independent test. Retain all initial negative or small-gain results.

The initial P100 input used log2 light/heavy Level2 values without the depositor's loading correction. That avoids treatment-pool-dependent feature QC, but can unfairly penalize orthogonal information through additive sample loading. For every individual P100 sample, subtract the mean across that sample's finite observed peptides before computing same-plate DMSO differences. This uses no other treatment samples, target RNA, or held-query labels. It is invariant to a common additive loading shift but may remove genuine global phosphorylation. Preserve missing masks, probe identities, controls, exact doses, source and target sets, both RNA outcome arrays and every query mask bitwise. Repeat the same model families and small source-only hyperparameter rules; freeze all sensitivity predictions before its target scoring. Do not select or replace the primary preprocessing based on results.

Important refinement: the PSP sample-offset routine uses plate-wide peptide medians, but this alone does NOT prove leakage of the final treatment-control contrast. With a common complete peptide set, its shared median term cancels exactly after subtraction, yielding the same centered contrast as a sample-local transformation. With unequal missing masks or treatment-dependent feature/sample filtering, that exact cancellation need not hold. Implement and test both the exact cancellation case and a missing-mask counterexample. Do not imply all Level3 processing is automatically invalid.

Retain the existing query-exposed bridge as a separate information regime. No GCP24h input is allowed for a forward6hRNA claim. Report comparator and control-record budgets, both scales, adverse results and the lack of verified cross-assay culture linkage.
