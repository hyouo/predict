# Mechanism-transfer v7: dated annotations as a mean prior, not a causal claim

Date: 2026-09-09. Retrospective development: the existing 30-context L1000 Phase II 24h/10uM slice and six test contexts were previously used. No first-use blind-test or SOTA claim. No target treated outcomes may enter fit, selection or feature construction.

New information: Broad Drug Repurposing Hub dated 2020-03-24 drug/sample tables, retrieved directly from Broad's public S3. Exact integer PubChem joins only; ambiguous mechanism annotation is excluded, not guessed. Missing annotations are not inactive drugs. Preserve dated non-commercial research notices. Test treatments and B scoring controls are blocked until the complete prediction freeze. Repeat the existing tissue-label source-exclusion scenario, with its own validation selection and explicit matched scoring coverage. At least 3 source contexts per query. 978 supplied features, no RNA-count renormalization.

Hypothesis: mechanism annotations can supply target-specific structure that is not already supplied by per-drug source-response interpolation. Learn a support-centred bilinear mean q(c,p) from training-context baseline features and drug annotations; then interpolate source residuals with a free-intercept RBF kernel. This equals ordinary kernel transfer plus gamma times [target prior minus source-interpolated prior]. Unknown-annotation drugs receive exactly the kernel fallback. This is a classical mean-function/kernel construction; the information increment, not renaming the algebra, is under test.

Fixed comparisons: zero, source mean, free-intercept full-baseline RBF and linear kernels; RBF augmented with (i) target/MOA annotation embedding, (ii) Morgan chemical fingerprint embedding, (iii) annotation rows permuted within covered compounds at seed 2701, (iv) source-response embedding, and (v) measured-target-masked baseline features. All input maps depend on permitted source/annotation data only. For bilinear priors use baseline PCA at most 12, drug feature uncentred SVD at most 32; source-response features also 32. Missing annotation rows remain zero. No drug names or hand-written target assignments supplied.

Ridge penalties for prior .1,1,10 (trace-scaled); residual kernel penalties .01,.1,1,10,100; prior blend gamma 0,.5,1. A common scalar in [0,1] is selected analytically on macro validation MSE for every family. Report the larger search of prior families; do not select winners on test. Freeze complete selected predictions before scoring. Preserve validation grids and adverse results. Exact-kernel special-case and zero-annotation fallback tests required.

Primary: full-effect context-macro MSE. Secondary: bias/centred error, amplitude, drug identity retrieval, and inherited exact-reference-matched cross-plate interaction-risk difference; report all drugs and annotation-covered subsets together. Paired resampling is conditional on fitted models, preprocessing and references; not independent biological inference. Tissue source exclusion must not be described as a randomized causal experiment. All follow-up adjustments are timestamped separately as development.
