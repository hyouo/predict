## Model families and tuning
Gamma-Poisson-shrunk training response log ratios, fixed shape 4; baseline A-control composition has 0.1 pseudocount per retained feature. All predictions use the same target baseline and softmax observation map, and never read query treatment library size. Compare: no effect; mean source response per drug; nearest baseline source cell; global baseline-kernel ridge; low-rank drug-response program operator with shared cell kernel; program-specific cell-kernel operator; matched permuted loading-to-gene ablation.

For the program operator, SVD of the mean training-cell drug response gives ranks 4/8/16. Project each training cell's residual response into the drug scores to obtain its program-to-output-gene map. Interpolate these maps from untreated target baseline, with program-specific gene weights from squared training-program loadings. This permits cross-gene target outputs. Matched ablation permutes loading-to-gene assignments, keeping model dimensions and tuning budget unchanged.

RBF bandwidth multipliers 0.3/1/3; ridge 0.01/0.1/1/10; output amplitudes 0.25/0.5/1/2. Validation cells select within-family hyperparameters by per-drug/per-cell mean predictive log-likelihood gain over no effect on pooled count proportions. Training responses/programs use ONLY the 32 training cells; validation outcomes select parameters but are not added as source-reference outcomes for test. Store every validation candidate, not just winners.

Freeze all final predictions, parameters, code/data/split hashes BEFORE loading the nine test-cell treatment arrays. Secondary metrics: composition L2 and baseline-weighted L2, observed log-effect error, drug and cell-specific discrimination, prediction amplitude. Report zero collapse and all failures. No model change after final test counts as confirmation.

## Evidence limits
Public data are not third-party secret. Entire target treatment profiles are held out, but source and target lines occur in the same pooled experiment: not an independent prospective experiment or nine independent studies. Pseudobulk observation and molecule counts do not supply independent biological replicates. Program-specific kernels, conjugate count likelihoods and empirical Bayes have precedents; no novelty is asserted merely from their names. Native State/MAP/PrePR-CT are not included in this finite classical-baseline experiment and cannot be claimed beaten. No paid compute, scheduled research or automatic superiority release.
